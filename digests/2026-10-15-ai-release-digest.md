## 3. Meta

### Your algorithm: new ways to shape what you see on Facebook (14 October 2026)
Source: https://about.fb.com/news/2026/10/introducing-your-algorithm-facebook/
What Meta says:
- A new ranking control called "Your algorithm" lets people type in topics they want to see more or less of in Feed and Reels, with large language models now reading that freeform text as an added ranking signal alongside existing engagement data.
- People can also give feedback on individual posts by tapping Interested or Not interested; Meta may ask a follow-up question, and recommendations update in real time. The three-dot menu that holds these controls has been moved to make them easier to find.

### How to use this at Touch Stone Publishers
1. Log this as a sector-brief and board-brief data point on platforms giving users direct, LLM-read control over ranking, relevant context for any brief on how AI is changing content distribution and discovery.
2. Treat this as a prompt to re-test how Touch Stone's Facebook content performs once readers can type in topic preferences directly. Worth a one-time check of whether TSP's own Facebook page shows up when a reader requests governance, leadership, or small-business content by name.

## 4. xAI (Grok)

### Introducing Grok Voice 3.0 (14 October 2026)
Source: https://x.ai/news/grok-voice-3
What xAI says:
- A new speech-to-speech model available now in the Voice Agent API as grok-voice-3.0, priced at $0.08 per minute, the same rate as Grok Voice 2.0, which this release deprecates.
- The grok-voice-latest alias now points to 3.0, so sessions using that alias upgraded automatically; the endpoint, session parameters, and events are unchanged from 2.0, so pinned 2.0 integrations only need to switch model IDs.
- xAI cites under one second of latency and says the model scores higher than two OpenAI models on a third-party benchmark it names. These are the vendor's own claims, not independently verified.

### How to use this at Touch Stone Publishers
1. No action needed on any TSP workflow today, since none currently run on xAI's Voice Agent API. Worth a calendar note only if a future voice feature is built on it, given the straightforward migration path from 2.0.

## Cross-vendor takeaways

2. xAI's voice model refresh continues the company's pattern of frequent point releases with same-price, drop-in upgrades, a lighter cadence than the multi-day Anthropic and Meta announcements covered this week.
