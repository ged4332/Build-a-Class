## 1. Anthropic

### Claude Frontier Academy (2 October 2026; not in earlier issues)
Source: https://www.anthropic.com/news/claude-frontier-academy
What Anthropic says:
- A $100 million commitment to train 10,000 Frontier Deployed Engineers by the end of 2027, aimed at the talent gap Anthropic identifies as one of the most pressing issues in AI implementation.
- A 12-week program; engineers who pass an assessment at the end earn the Claude Frontier Deployed Engineer badge, with the first badges expected in early 2027. Cohorts currently run in San Francisco, New York, and London.
- Participation is by nomination. Organizations ask their Anthropic account team or Partner Account Manager whether they are eligible. Cohorts from Accenture, Bain, CBA, Deloitte, McKinsey, Morgan Stanley, and Novo Nordisk are already underway.

### How to use this at Touch Stone Publishers
1. Log this as a board-brief data point on how frontier labs are now investing directly in enterprise talent pipelines, not just selling API access. A $100 million training commitment with named Big Four and MBB cohort partners is a concrete signal for any brief on AI adoption economics in professional services.
2. Note the nomination-only structure as context, not an action. TSP is not an Anthropic enterprise account at this scale, so this is a watch item for how the market for AI-fluent talent is developing, not a program to apply to today.

## 2. OpenAI

### Agents API pricing (29 September 2026, DevDay; billing began 5 October 2026)
Source: https://developers.openai.com/api/docs/pricing
What OpenAI says:
- Agents API standard pricing is $5 per million input tokens, $0.50 per million cached input tokens, and $25 per million output tokens.
- Billing for Agents API usage began 5 October 2026, roughly a week after the API's DevDay debut in public beta.

### How to use this at Touch Stone Publishers
1. Treat this as the number to model before piloting the Agents API for the outreach-review loop mentioned in the 1 October issue. At $25 per million output tokens, a sustained multi-agent triage workflow needs a quick cost estimate before committing, now that free preview usage has given way to billed usage.
