## 2. OpenAI

OpenAI DevDay 2026 ran 29 September at Fort Mason, San Francisco. OpenAI calls it the biggest DevDay yet, with more than 20 announcements across ChatGPT, Codex, models, and new ways of working with AI. The items below are the ones with enough detail in search to report faithfully.

### GPT-6.1 Sol (29 September 2026)
Sources: https://openai.com/index/introducing-gpt-6-1-sol/ and https://developers.openai.com/api/docs/models/gpt-6.1-sol
What OpenAI says:
- A major upgrade to GPT-6 Sol with exceptionally strong performance on agentic coding, computer use, and professional work. Nearly matches GPT-6 Astra's intelligence on those same tasks at one-fifth of Astra's standard token prices.
- Pricing: $2 per million input tokens, $10 per million output tokens, and cached input at $0.10 per million tokens, a 95 percent discount versus standard input and 50 percent less than GPT-6 Sol's own cached rate.
- Available now to all API, Plus, Pro, Business, Enterprise, and Edu users. A GPT-6.1 Sol Ultrafast variant is coming soon.

### Agents API public beta (29 September 2026)
Source: https://openai.com/index/devday-2026-recap/
What OpenAI says:
- Agents that can take on ongoing responsibilities, not just answer single requests. The Agents API is in public beta with hosted execution, memory, tools, and multi-agent support.
- Now supports computer use, so developers can build agents that interact with software directly to complete tasks. Brings Codex's multi-agent capabilities, tool search, tool calling, and context compaction into any application built on the API.

### Ultrafast speed tier (29 September 2026)
Source: https://openai.com/index/devday-2026-recap/
What OpenAI says:
- A premium speed tier for latency-sensitive workloads: up to 8 times faster token generation in Codex, around 300 tokens per second, and up to 6 times faster in the API.

### ChatGPT Apps and the Apps SDK (29 September 2026)
Source: https://openai.com/index/introducing-apps-in-chatgpt/
What OpenAI says:
- A new generation of apps that run inside ChatGPT conversations, responding to natural language with interactive interfaces usable directly in the chat. Developers build them with the new Apps SDK, in preview.
- The Apps SDK is open source and built on the Model Context Protocol, extending MCP so developers can design both the logic and the interface of an app, intended to run anywhere that adopts the standard.
- OpenAI frames this as opening ChatGPT as a shared surface for its 1.2 billion weekly users, where developers can launch native experiences directly, alongside a new Plugin Creator tool and a redesigned submission flow.

### How to use this at Touch Stone Publishers
1. Route the highest-volume Codex and API work on the Build-a-Class site through GPT-6.1 Sol first. Near-Astra quality at a fifth of the price, with cached input 95 percent cheaper than standard, makes it the new default before reaching for Astra itself.
2. Pilot the Agents API's multi-agent and memory features for the outreach-review loop. An agent that holds ongoing responsibility for triaging replies, rather than being re-prompted each time, matches the standing task Glenn already runs manually.
3. Evaluate the Ultrafast tier for any latency-sensitive live use, such as the Wednesday LinkedIn Live show's real-time research assist, where an 8x speed gain in Codex could matter more than raw model quality.
4. Scope what a Touch Stone Publishers ChatGPT app could look like, a Pryor prompt-sheet companion or a board-brief lookup tool, now that the Apps SDK is open and built on MCP. This is the same packaging shift as the custom-GPT-to-plugin migration from the 18 September issue, one level further.

The Agents API's memory and multi-agent support, Meta's Enterprise Platform from 29 September, and Anthropic's Claude Partner Network from earlier issues are all the same bet: businesses want a platform to build agents on, not a single model to call.
